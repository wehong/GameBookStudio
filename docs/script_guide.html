게임북 스크립트 가이드

GameBook Studio의 스크립트(.gb)로 쓸 수 있는 모든 문법을 정리한 문서입니다. 처음이라면 1장 ~ 3장을 순서대로 읽고, 나머지는 필요할 때 찾아보세요. 런처의 문법 가이드 버튼이나 게임 창(개발 모드)의 F1로 언제든 열 수 있습니다.

1. 한눈에 보기

게임북은 단락들로 이루어집니다. 플레이어는 한 번에 단락 하나를 보며, 화면에는 이미지 한 장 + 본문 + 선택지가 나옵니다. 선택지를 고르면 다른 단락으로 넘어갑니다.

default 열쇠 = false              # 변수의 처음 값

label start:                      # 단락 'start' (게임은 여기서 시작)
    image "room.png"              # 이 단락의 이미지
    "낯선 방에서 눈을 떴다."        # 본문
    choice "문을 연다" -> 문        # 선택지: 고르면 '문' 단락으로
    choice "창밖을 본다" -> 창문

label 창문:
    "창틀 아래에서 열쇠를 찾았다."
    set 열쇠 = true               # 변수 값 바꾸기
    choice "문으로 간다" -> 문

label 문:
    if 열쇠:                      # 조건에 따라 다른 내용
        "열쇠가 맞는다. 문이 열린다."
        end "탈출"                # 엔딩
    "문은 잠겨 있다."
    choice "방을 둘러본다" -> 창문

이 예제에 나온 문장이 스크립트 문법의 거의 전부입니다.

문장하는 일자세히
label 이름:단락을 만든다3장
"글"본문 한 문단4장
image "파일"단락 이미지5장
choice "글" -> 단락선택지6장
default 이름 = 값변수의 처음 값7장
set 이름 = 값변수 바꾸기 (+=, -=도 가능)7장
if 조건: / elif / else:조건 분기9장
goto 단락다른 단락으로 바로 이동11장
end "제목"엔딩12장
# 메모주석 (게임에 안 보임)2장

2. 기본 규칙

파일과 폴더

  • 스크립트는 프로젝트의 script 폴더에 있는 .gb 파일입니다. 파일은 UTF-8로 저장합니다 (VS Code 등 요즘 편집기는 기본이 UTF-8입니다).
  • 파일을 여러 개로 나눠도 됩니다. script 폴더(하위 폴더 포함)의 모든 .gb 파일이 하나로 합쳐집니다. 예) 1장.gb, 2장.gb, 엔딩.gb
  • 다른 파일에 있는 단락으로도 그냥 이름만 써서 이동할 수 있습니다.

들여쓰기

Python처럼 들여쓰기로 구조를 나타냅니다. 단락에 속한 문장은 label 줄보다 들여쓰고, if나 선택지 블록에 속한 문장은 그보다 한 번 더 들여씁니다.

label 숲:                 # 들여쓰기 없음
    "숲이다."              # 단락 안: 4칸
    if 횃불:
        "횃불이 밝다."      # if 안: 8칸
  • 같은 블록의 줄은 들여쓰기 칸 수가 정확히 같아야 합니다. 4칸을 권장합니다.
  • 탭 문자는 4칸으로 계산됩니다. 게임북 확장을 설치한 VS Code에서는 Tab 키를 누르면 4칸 공백이 들어갑니다.
  • label과 default는 들여쓰지 않고 맨 앞에 씁니다.
  • 콜론(:)으로 끝나는 줄(label, if, elif, else, 효과가 있는 choice) 다음 줄은 반드시 들여씁니다.

주석

# 뒤의 내용은 무시됩니다. 줄 전체를 주석으로 쓸 수도, 문장 끝에 붙일 수도 있습니다. 따옴표 안의 #은 주석이 아니라 글자입니다.

# 2장: 동굴 편
label 동굴:
    "#3 번 갱도"            # ← 이 '#3'은 본문에 그대로 보입니다
    set 체력 -= 1           # 동굴은 춥다

빈 줄

빈 줄은 아무 의미가 없습니다. 읽기 좋게 단락 사이에 자유롭게 넣으세요.

3. 단락 — label

label 단락이름:
    (내용)
  • 이름에는 한글, 영문, 숫자, _(밑줄) 을 쓸 수 있습니다. 띄어쓰기는 안 되므로 동굴_입구처럼 밑줄로 잇습니다.
  • 숫자만으로 된 이름도 됩니다. 종이 게임북처럼 label 1:, label 147: 식으로 만들 수 있습니다.
  • 모든 파일을 통틀어 같은 이름의 단락은 하나만 있어야 합니다.
  • 게임은 start 단락에서 시작합니다. 다른 단락에서 시작하려면 game.json의 "start"를 바꿉니다.
  • 단락 안에는 내용이 한 줄 이상 있어야 합니다.

단락은 위에서 아래로 차례대로 실행되어 한 화면을 만듭니다. 자세한 실행 순서는 13장에 있습니다.

4. 본문

한 문단

큰따옴표(")나 작은따옴표(')로 감쌉니다. 문장 하나가 화면의 한 문단이 됩니다.

label 바닷가:
    "파도 소리가 들린다."
    "멀리 등대가 보인다."      # 두 번째 문단

따옴표 안에서 쓸 수 있는 특수 표기:

표기결과
\n줄바꿈
\"큰따옴표 글자 ("그가 \"멈춰!\" 라고 외쳤다.")
\'작은따옴표 글자
\\역슬래시 글자

큰따옴표가 많은 대사는 작은따옴표로 감싸면 편합니다: '"멈춰!" 그가 외쳤다.'

여러 줄 본문

긴 글은 따옴표 세 개(""")로 감쌉니다. 쓴 그대로 줄이 바뀌고, 빈 줄도 그대로 빈 줄로 보입니다. 앞쪽 공통 들여쓰기는 자동으로 지워집니다. 이 안에서는 \n 같은 특수 표기가 처리되지 않습니다.

label 편지:
    """
    친애하는 벗에게.

    이 편지가 닿을 즈음이면
    나는 이미 바다 위에 있을 걸세.
    """

변수 값 끼워 넣기 — {변수}

본문과 선택지 글에 {변수이름}을 쓰면 그 자리에 현재 값이 들어갑니다.

default 금화 = 10
default 동료 = "엘라"

label 여관:
    "{동료}가 지갑을 열어 보였다. 남은 금화는 {금화}개."
    choice "방을 잡는다 (금화 {금화}개 중 3개)" -> 방
  • 참/거짓 값은 "참", "거짓"으로 표시됩니다.
  • 중괄호 안에는 변수 이름만 쓸 수 있습니다. {금화 * 2} 같은 계산은 안 되므로, 필요하면 먼저 set으로 계산해 두세요.
  • 중괄호 글자 자체를 쓰려면 {{, }}로 씁니다.
  • 값을 넣은 적 없는 변수는 0으로 표시됩니다.

5. 이미지 — image

image "cave.png"           # images 폴더의 cave.png
image "items/key.png"      # images/items 폴더의 key.png
image none                 # 이미지 없음 (none 대신 없음 도 가능)
  • 이미지는 그 단락에서만 보입니다. 다음 단락에 image가 없으면 이미지 없이 본문만 나옵니다.
  • 한 단락에서 image를 여러 번 실행하면 마지막 것이 쓰입니다. 그래서 if 안에 넣어 상황별로 다른 그림을 보여 줄 수 있습니다.
  • 이미지는 화면 폭에 맞게 자동으로 줄어듭니다 (늘어나지는 않음). 가로 960px 정도면 충분합니다.
  • PNG, JPG, GIF, WebP, BMP를 쓸 수 있습니다. 게임 창과 HTML로 내보낸 게임 모두에서 보입니다. (GIF는 첫 장면만 보입니다)
  • 파일 이름은 대소문자까지 정확히 맞춰 쓰세요. Windows에서는 Cave.png와 cave.png가 같지만 macOS·Linux에서는 다른 파일입니다. 검사 기능이 이를 알려 줍니다.
  • 그림은 런처의 이미지 폴더 버튼으로 연 images 폴더에 넣습니다. 그림이 창보다 크면 창에 맞게 줄여서 보여 줍니다.
label 등대:
    image "lighthouse_dark.png"
    if 불_켬:
        image "lighthouse_lit.png"     # 조건이 맞으면 이 그림으로 바뀜
    "등대가 서 있다."

6. 선택지 — choice

기본

choice "보여 줄 글" -> 이동할단락
  • 선택지는 적은 순서대로 화면 아래에 나열되고, 앞에서부터 번호(1~9)가 붙습니다. 플레이어는 클릭하거나 숫자 키로 고릅니다.
  • 선택지 글에도 {변수}를 쓸 수 있습니다.

조건이 있는 선택지 — if

choice "열쇠로 문을 연다" if 열쇠 -> 방안
choice "빵을 산다" if 금화 >= 2 -> 빵집
choice "처음 보는 길로 간다" if not visited("뒷길") -> 뒷길
  • 조건이 맞지 않으면 그 선택지는 숨겨집니다.
  • game.json에서 "show_locked_choices": true로 바꾸면 숨기지 않고 흐리게(고를 수 없게) 보여 줍니다. "열쇠가 있었다면…" 하고 아쉬움을 주는 연출에 좋습니다.
  • 조건식 쓰는 법은 8장을 보세요.

고를 때 효과가 있는 선택지

선택지 줄 끝에 콜론(:)을 붙이고 아래에 들여써서 set이나 if를 쓰면, 그 선택지를 고른 순간 실행된 뒤 다음 단락으로 넘어갑니다.

label 상점:
    "상인이 물건을 늘어놓았다. 금화 {금화}개."
    choice "빵을 산다 (2금화)" if 금화 >= 2 -> 상점:
        set 금화 -= 2
        set 빵 += 1
    choice "가게를 나선다" -> 시장
  • 블록 안에는 set과 if만 쓸 수 있습니다. 본문, 이미지, 다른 선택지는 넣을 수 없습니다. 고른 뒤에 보여 줄 글은 이동할 단락에 쓰세요.
  • 위 예처럼 같은 단락으로 돌아오게 하면 상점·대화처럼 반복 선택하는 장면을 만들 수 있습니다.

if 안의 선택지

if 블록 안에 선택지를 넣으면, 조건이 맞을 때만 그 선택지들이 추가됩니다. 조건 선택지를 여러 개 같은 조건으로 묶을 때 편합니다.

label 갈림길:
    "길이 셋으로 갈라진다."
    choice "왼쪽 길" -> 왼쪽
    if 지도:
        "지도에 숨은 길이 표시되어 있다."
        choice "숨은 길" -> 비밀_길
        choice "지도를 다시 본다" -> 지도_보기

선택지가 하나도 없으면?

선택지·goto·end가 하나도 실행되지 않은 단락은 막다른 곳이 됩니다. 플레이어에게는 "이야기가 여기서 멈췄습니다"와 함께 [뒤로 가기 / 처음부터] 버튼만 나옵니다. 검사 기능이 이런 단락을 경고로 알려 주므로, 조건 선택지만 있는 단락에는 조건 없는 선택지나 else를 하나 두세요.

7. 변수 — default, set

변수는 이야기의 상태(아이템, 돈, 호감도, 이미 한 일 등)를 기억하는 이름표입니다.

처음 값 — default

default 금화 = 10
default 횃불 = false
default 동료 = "엘라"
default 최대체력 = 12
default 체력 = 최대체력      # 위에서 정한 변수를 써도 됨
  • label 밖, 맨 앞(들여쓰기 없이)에 씁니다. 보통 파일 맨 위에 모아 둡니다.
  • 새 게임을 시작할 때 위에서부터 차례로 값이 정해집니다. 파일이 여러 개면 파일 이름 순서입니다.
  • default 없이 set으로만 써도 동작하지만, 처음 값을 분명히 적어 두는 편이 실수가 적습니다.

값 바꾸기 — set

set 횃불 = true          # 값 넣기
set 금화 += 5            # 더하기
set 체력 -= 2            # 빼기
set 공격력 = 힘 * 2 + 1  # 계산한 값 넣기
set 동료 = "카이"        # 글자 값
set 주사위 = random(1, 6)

이름 규칙과 값의 종류

  • 변수 이름에는 한글, 영문, 숫자, _를 쓸 수 있고 숫자로 시작할 수 없습니다. 예) 금화, has_key, 열쇠2
  • if, and, not, true 같은 문법 단어는 이름으로 쓸 수 없습니다.
종류예설명
정수3, -1, 100개수, 체력, 점수
소수1.5/ 나눗셈 결과도 소수가 됩니다
참/거짓true, false, 참, 거짓아이템 보유, 사건 발생 여부 (True/False도 가능)
글자"엘라", '북쪽'이름, 선택한 길 등

값을 넣은 적 없는 변수는 0(거짓)으로 취급됩니다. 그래서 if 열쇠:는 열쇠를 한 번도 설정하지 않았어도 오류 없이 거짓이 됩니다. 반대로 이름을 잘못 쓰면(예: 열쇄) 조용히 0이 되므로, 검사 기능이 "값을 넣는 곳이 없는 변수"를 경고로 알려 줍니다.

8. 조건식

if, elif, 조건 선택지, set의 오른쪽에 쓰는 식입니다.

비교

연산뜻예
==같다동료 == "엘라"
!=다르다방향 != "북"
<, <=작다, 작거나 같다체력 <= 0
>, >=크다, 크거나 같다금화 >= 3

1 <= 주사위 <= 3처럼 이어서 쓸 수도 있습니다. =는 하나만 쓰면 비교가 아니라 오류입니다(==로 쓰세요).

논리

연산뜻예
and그리고열쇠 and 횃불
or또는금화 >= 10 or 할인권
not아니다not visited("동굴")
( )묶기(열쇠 or 곡괭이) and not 함정

변수 이름만 쓰면 "참인가?"라는 뜻입니다. 0, false, 빈 글자 ""는 거짓이고 나머지는 참입니다.

계산

연산뜻예
+, -, *더하기, 빼기, 곱하기힘 * 2 + 1
/나누기 (소수)7 / 2 → 3.5
//나누기 (몫, 정수)7 // 2 → 3
%나머지날짜 % 7

글자끼리 +로 이을 수도 있습니다: set 칭호 = 이름 + " 경".

9. 조건 분기 — if, elif, else

if 조건:
    (조건이 참일 때)
elif 다른조건:
    (앞 조건은 거짓이고 이 조건이 참일 때)
else:
    (모두 거짓일 때)
  • elif와 else는 없어도 됩니다. elif는 여러 개 쓸 수 있습니다.
  • 위에서부터 처음으로 참인 한 곳만 실행됩니다.
  • 안에는 본문, 이미지, set, 선택지, goto, end, 또 다른 if까지 무엇이든 넣을 수 있습니다.
  • 줄 끝 콜론(:)을 잊지 마세요. else는 반드시 else:로 씁니다.
label 문지기:
    if 호감도 >= 5:
        "문지기가 웃으며 길을 비켜 준다."
        choice "들어간다" -> 성안
    elif 금화 >= 10:
        "문지기가 손바닥을 내민다."
        choice "금화 10개를 건넨다" -> 성안:
            set 금화 -= 10
        choice "돌아선다" -> 성문앞
    else:
        "문지기가 창을 겨눈다. 썩 꺼져라!"
        choice "물러난다" -> 성문앞

10. 함수 — visited, random

조건식과 set에서 쓸 수 있는 함수는 두 가지입니다.

visited("단락") — 방문 횟수

그 단락에 들어간 횟수를 돌려줍니다. 지금 보고 있는 단락도 들어온 순간 1이 늘어난 뒤 계산됩니다.

상황값
한 번도 안 간 단락0
지금 처음 들어와 있는 단락1
두 번째로 들어와 있는 단락2
label 마을:
    if visited("마을") == 1:
        "처음 와 보는 마을이다. 사람들이 낯선 눈으로 쳐다본다."
    else:
        "다시 마을로 돌아왔다."
    choice "우물을 살펴본다" if not visited("우물") -> 우물

random(최소, 최대) — 무작위 수

최소 이상 최대 이하의 정수 하나를 돌려줍니다. 주사위 판정이나 무작위 사건에 씁니다.

set 주사위 = random(1, 6)
if random(1, 100) <= 30:         # 30% 확률
    "갑자기 비가 쏟아진다."
  • 뒤로 가기나 불러오기로 같은 선택을 다시 해도 결과가 같습니다. 플레이어가 "다시 굴리기"를 반복해 결과를 바꿀 수 없게 하기 위해서입니다.
  • 결과를 플레이어에게 보여 주고 싶다면 변수에 저장해서 {주사위}처럼 표시하세요.

11. 이동 — goto

goto 단락이름

선택지 없이 다른 단락으로 넘어갑니다. goto 아래의 문장은 실행되지 않습니다.

  • 지금 단락에서 이미 보여 준 본문(또는 이미지)이 있으면, 화면에 [계속] 버튼이 생기고 누르면 이동합니다.
  • 보여 준 것이 없으면 곧바로 이동합니다. 그래서 아래처럼 내용 없이 조건만 따지는 "분기 단락"을 만들 수 있습니다.
  • goto 앞에서 실행된 선택지는 무시됩니다.
label 귀환:                     # 화면에 안 보이는 분기 단락
    if 보물 >= 3:
        goto 엔딩_부자
    elif 보물 >= 1:
        goto 엔딩_보통
    else:
        goto 엔딩_빈손

단락끼리 서로 goto만 하며 끝없이 도는 경우, 200번이 넘으면 오류로 멈춥니다.

12. 엔딩 — end

end "엔딩 제목"
end                    # 제목 없이
  • 이야기가 끝납니다. 본문 아래에 — 엔딩 제목 —이 표시되고, [뒤로 가기 / 처음부터 다시 하기 / 타이틀로] 버튼이 나옵니다.
  • end 아래의 문장, 그리고 그 단락에서 앞서 만든 선택지는 모두 무시됩니다.
  • 엔딩은 몇 개든 만들 수 있습니다. 런처와 검사 결과에 엔딩 개수가 표시됩니다.

13. 실행 순서 이해하기

단락은 다음 순서로 처리됩니다. 이것만 알면 대부분의 동작을 예상할 수 있습니다.

  1. 단락에 들어가면 먼저 그 단락의 방문 횟수(visited)가 1 늘어납니다.
  2. 문장을 위에서 아래로 실행하며 화면을 채웁니다. 본문은 문단으로 쌓이고, 이미지는 마지막 것으로 정해지고, 선택지는 조건이 맞는 것만 목록에 쌓입니다. set은 그 자리에서 바로 값을 바꿉니다.
  3. goto나 end를 만나면 그 자리에서 멈춥니다.
  4. 화면이 표시되고 플레이어가 선택지를 고릅니다.
  5. 고른 선택지에 효과 블록이 있으면 실행하고, 다음 단락으로 가서 1부터 반복합니다.

순서가 중요한 예: 아래 단락에서 본문은 set보다 먼저 실행되므로 바뀌기 전 값이 보입니다.

label 함정:
    "체력: {체력}"           # 바뀌기 전 값
    set 체력 -= 3
    "가시에 찔렸다! 체력: {체력}"   # 바뀐 뒤 값

선택지의 조건도 그 줄이 실행되는 시점의 값으로 판단합니다. 같은 단락에서 set으로 값을 바꾼 뒤의 선택지에는 바뀐 값이 적용됩니다.

14. 자주 쓰는 패턴

아이템을 한 번만 얻기

선택지 효과로 값을 바꾸고 같은 단락으로 돌아오면, 조건 때문에 선택지가 사라집니다.

label 오두막:

체력과 게임 오버

주사위 판정

굴리는 순간을 선택지 효과에 두면 "던진다"는 느낌이 납니다.

    choice "뛰어넘는다" -> 점프:

        choice "계속 간다" -> 건너편
    else:
        "발이 미끄러졌다!"

        choice "기어오른다" -> 절벽

무작위 사건

16. 편집기와 실행

Ren'Py처럼 스크립트는 평소 쓰는 텍스트 편집기(VS Code 추천)로 쓰고, 런처와 게임 창으로 확인합니다.

처음 한 번: 편집기 준비

  1. VS Code를 설치합니다. (다른 편집기도 됩니다)
  2. 런처의 VS Code 확장 설치를 누릅니다. .gb 파일에 색이 입혀지고, 들여쓰기가 4칸 공백으로 맞춰지고, 문장 틀(조각)을 쓸 수 있게 됩니다.
  3. 다른 편집기를 쓰려면 편집기 고르기에서 고릅니다. 목록에 없으면 직접 지정… 에 실행 명령을 적습니다. {file}은 파일, {line}은 줄 번호, {project}는 프로젝트 폴더로 바뀝니다.

예) code -g {file}:{line} 예) subl {file}:{line} 예) notepad++ -n{line} {file}

쓰고 확인하기

  • 스크립트 편집하기: 편집기로 프로젝트의 스크립트를 엽니다. (VS Code는 프로젝트 폴더째로 열려서 왼쪽에서 다른 파일도 볼 수 있습니다)
  • 실행하기: 게임 창을 개발 모드로 엽니다. 게임 창을 띄워 둔 채 편집기에서 저장하면 바로 다시 읽어서, 보고 있던 단락이 새 내용으로 바뀝니다.
  • 오류가 있으면 게임 창에 오류 목록이 나옵니다. 위치를 누르거나 F4를 누르면 편집기에서 그 줄이 열립니다. 고쳐서 저장하면 저절로 게임으로 돌아옵니다.
  • 런처의 프로젝트 이름 아래에는 단락·선택지 수와 오류·경고 수가 나오고, 스크립트를 저장할 때마다 새로 계산됩니다.

  • 스크립트 검사: 문제 목록을 보여 줍니다. 항목을 누르면 편집기에서 그 줄이 열립니다.
  • HTML 로 내보내기: 스크립트와 그림을 모두 담은 HTML 파일 하나를 프로젝트의 dist 폴더에 만듭니다. 받은 사람은 브라우저로 열기만 하면 플레이할 수 있고 휴대폰에서도 열립니다. 저장은 그 브라우저에 됩니다.
  • 삭제(프로젝트 목록 아래, 또는 Delete 키): 고른 프로젝트 폴더를 확인 후 바로 지웁니다. 휴지통을 거치지 않으므로 되돌릴 수 없습니다. 필요하면 먼저 프로젝트 폴더를 열어 복사해 두세요.
  • 배포 파일 만들기: Python과 pygame-ce가 설치된 컴퓨터에서 python play.py로 실행하는 zip 파일을 만듭니다.

17. 설정 — game.json

프로젝트 폴더의 game.json은 런처의 설정 (game.json) 버튼으로 편집기에서 열 수 있습니다. 저장하면 게임 창에 바로 반영됩니다.

항목기본값설명
title게임 제목 (타이틀 화면, 창 제목)
author지은이 (타이틀 화면)
start"start"시작 단락 이름
window[1024, 760]처음 창 크기 [가로, 세로]. 이 크기일 때 글자 크기가 font_size 그대로이고, 창을 키우면 함께 커집니다
font""본문 글꼴. 비우면 고딕체(나눔고딕), "serif"는 명조체(나눔명조), 또는 프로젝트 폴더에 넣은 글꼴 파일 "fonts/내글꼴.ttf" (게임 창에서만 적용되고 HTML에서는 고딕/명조 중 하나로 보입니다)
font_size15본문 글자 크기
show_locked_choicesfalsetrue면 조건이 안 맞는 선택지를 흐리게 보여 줌
title_image""타이틀 화면 이미지 (images 폴더 기준)
theme"paper""paper"(종이) 또는 "night"(어두운 화면)

JSON 형식이므로 글자는 큰따옴표로 감싸고, 항목 사이에 쉼표를 넣고, 마지막 항목 뒤에는 쉼표를 넣지 않습니다.
