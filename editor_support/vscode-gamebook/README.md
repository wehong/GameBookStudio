# GameBook Script (게임북 스크립트) — VS Code 확장

GameBook Studio 의 `.gb` 스크립트를 VS Code 에서 편하게 쓰게 해 줍니다.

- 구문 강조 (label, choice, 문자열, `{변수}`, 주석 …)
- 4칸 들여쓰기, `:` 다음 줄 자동 들여쓰기, `Ctrl+/` 주석
- 문장 조각: `label`, `choice`, `choiceif`, `choiceset`, `if`, `set`, `goto`, `end`, `image`, `default` 를 치고 Tab

GameBook Studio 런처의 **VS Code 확장 설치** 버튼으로 설치할 수 있습니다.
